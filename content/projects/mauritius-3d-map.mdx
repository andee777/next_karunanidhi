Mauritius 3D Map is an interactive 3D map of Mauritius with draggable rotation, scroll-to-zoom, and clickable landmark markers laid over a glassmorphism interface. It's a personal project exploring 3D map rendering for a place I know well, built on the same React Three Fiber stack as my other WebGL experiments.

Built with Next.js 16, `@react-three/fiber` and `drei`, Three.js, and Tailwind v4.
