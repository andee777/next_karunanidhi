A companion piece to [Rendez-vous en Terre Inconnue — Interactive Map](/projects/rdv-terre-inconnue-map), this is a clustered Leaflet map visualizing data on French people's favorite countries. Same clustering approach, different dataset — built right after the first map to see how well the pattern generalized.

Built with Next.js 15, `react-leaflet` with marker clustering, and `supercluster`.
