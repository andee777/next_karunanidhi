Habit Tracker is a small personal app for building daily habits — tap a habit to log it for the day, and a stats page charts streaks and trends over time. It has its own account system, register and login, so habits and history are tied to a user rather than stored locally.

Built with Next.js 16, Drizzle ORM for the schema and migrations, NextAuth for authentication, shadcn/Radix components, and GSAP/Motion for the interface animations.
