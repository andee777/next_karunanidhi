Bet Data Validator is the internal data-ops tool behind [Bet Tracker & Analytics](/projects/bet-tracker-analytics) — it reconciles teams, leagues, bets, and match data pulled from external providers like Fotmob and Sofascore against what's stored in the app's own database. It handles deduplicating teams that come in under different names, managing name aliases, and syncing scores, leagues, and live match state.

Built with Next.js 16, Drizzle ORM over Postgres, `jose` for JWT auth, and TanStack Table/Virtual for browsing large, dense datasets without the UI choking.
